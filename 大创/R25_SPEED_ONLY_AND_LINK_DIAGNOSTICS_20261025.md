# R25 / 网页 v40：速度环观察与链路取证

本版本处理四轮曲线、临时绕过外环、关闭高频 RAM 日志，以及跨重连保留故障记录。
未修改速度环/角速度环/方向环 PID、控制周期、TOF 阈值或串口波特率。

## 已实现

- TEL 27字段中的 A..D 目标（4..7）和实际（12..15，除10）均可画图；支持单轮、四轮同屏。
- 观察轮速会选择 TEL，观察外环选择 ATEL，避免数据流与曲线选择不匹配。
- 速度专用模式先 STOP，回读 ATEL mode=0、速度关闭，再允许用户手动 ARM/SPEED。
  W/S/A/D 使用 DRV，Q/E 和外环启动/自动测试被禁用。退出也先停车，不自动恢复旧运动。
- 新增 DKEEP，只刷新尚未过期、已启用的直接驱动租约；外环、手柄占用、停车或
  300ms租约过期均拒绝。网页约120ms保活，200ms等待直接串口应答，失败停车。
- `App/Inc/app_config.h` 默认 `APP_ENABLE_TUNING_LOG=0`，整块 HLOG/WLOG
  共享缓冲和采集/下载实现编译移除。切回1重新编译可恢复，不改 PID。
- 网页新增故障历史：最近40条跨刷新保留，最近3条附原始证据。
  区分打开失败、命令超时、USB移除、接收结束/异常、写失败、损坏字节、
  桥接离线、手动断开与停车重验证。每条记录时间、命令、写完成、接收间隔等已知条件；
  未定位的硬件根因标为未知。正常 RX 不持久化到浏览器存储。

## 结论边界及使用

关闭日志释放内存是确定的，是否改善运动中断联必须对照实际复现。
原日志是 RAM 采集，下载时才发串口，不能据缓冲容量推断串口一直被100Hz日志塞满。
实时曲线保持原低频（TEL单独约3.3Hz，与TOF同开约2Hz），用于观察趋势，
不能替代100Hz原始数据评估速度环瞬态。

用默认“启动上位机.bat”进入串口直连，停车后刷新页面，确认 v40/R25。
先选择速度专用模式，再手动ARM、启用速度环，按住W/S/A/D观察曲线。
外环恢复需退出此模式，不会自动恢复之前的目标。
再次出现卡顿/停车/断联，及时导出链路诊断；新文件含 incidentHistory，
无需在每次重新连接前抢着导出。旧v39文件缺失的历史不能事后补回。
