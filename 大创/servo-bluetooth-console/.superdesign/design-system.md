# ST3215 console design system
A completely new standalone local control page, not a redesign of vehicle-console. Chinese desktop-first industrial instrument layout, responsive to mobile. No external imagery, no logo, no invented badge/brand mark. System sans-serif and monospace only. Background #0b1018, panels #111925, borders #263345, text #edf3f8, muted #93a5b8, primary cyan #5dd8df, stop red #ef6868. 8px spacing grid, 10px panel radii, 44px minimum buttons. Header with product name and BLE connect/disconnect. Left column motion controls (relative degrees, positive/negative direction, °/s speed, separate relative/continuous/reciprocation actions, prominent Stop). Right column an angle command dial clearly labeled target not feedback, actual MCU mode/version/command/error status, timestamped communication log. Connection panel offers type I (FFE0/FFE1) and type II (FFE0 write FFE2 notify FFE1), mirroring serial.keysking.com behavior only. No serial/GATT implementation jargon in the main motion flow. All motion disabled until version-confirmed. Screen default disconnected. No demo values represented as hardware state. Space key stops while connected.
