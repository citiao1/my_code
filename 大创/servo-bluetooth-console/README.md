# ST3215 蓝牙舵机控制台

独立上位机，采用已确认的 Superdesign 布局。原 `vehicle-console` 界面没有改动。

在本目录的终端运行 `node server.mjs`（或 `npm start`），然后用桌面 Chrome / Edge 打开 http://127.0.0.1:8870/ 。关闭服务用 Ctrl+C。不需要 PowerShell 启动脚本或额外 npm 依赖。

点击“连接蓝牙”选择 WHEELTEC-IOS；再次连接会优先使用同一浏览器曾授权的设备。通用Ⅰ型为 FFE0 服务、FFE1 写入/通知；通用Ⅱ型为 FFE0 服务、FFE2 写入、FFE1 通知，与参考页面 https://serial.keysking.com/#/ 的配置一致。其他页面或程序应断开同一模块。

控制器屏幕和网页必须核对为 `SERVO BLE R7`。蓝牙侧 USART2：PD5 TX → 模块 RX，PD6 RX ← 模块 TX，9600、8N1、共地。舵机转接板仍使用 USART3：PC10 TX、PC11 RX，1 Mbps；舵机 ID 1。

支持相对定角度 0.1–720°、正/反向持续旋转、指定角度往复、速度 10–120°/s。“停止运动”及空格键停止；输入框内的空格不会触发。切出页面会请求停止；关闭/断联后，控制器最多约 3 秒心跳超时停止远程运动。停止会关闭扭矩。圆盘显示指令预览，不代表实测角度。

R7 连续旋转在扭矩使能后单独写入速度，并读回目标速度和扭矩状态；每 100 ms 检查实际转速。持续 1.5 秒无有效方向转速时停止并计入设备异常。恢复通信不会自行恢复运动，需重新执行。

日志保留人工命令、应答确认、设备状态变化和异常；正常 K 心跳在后台运行，不刷屏。相对运动应答丢失不会自动重发。运行 `npm test` 可检查协议、分包接收、心跳与停止仲裁。

协议：`@序号,操作[,参数1,参数2]*HH\n`，HH 是 @ 和 * 之间 ASCII 字节的 XOR。M/A 参数为有符号 0.1°、counts/s；C 参数为 ±1、counts/s；V 查询版本状态，K 心跳，S 停止。应答必须通过校验和序号匹配才更新页面。

设计预览：https://p.superdesign.dev/draft/4787bb4d-8d0b-4600-8dfb-9da1261cd67c 。本地已实现蓝牙功能，预览仅用于布局确认。
