# 网页上位机与 VOFA+ 同时使用

## 连接

- 设备类型：`TCP Client`
- 地址：`127.0.0.1`
- 端口：`1347`
- 协议引擎：`FireWater`
- 握手数据：留空

网页使用 `http://127.0.0.1:8088`，连接方式保持“本地桥接 + VOFA”。真实串口或 BLE 只由桥接程序占用，网页和 VOFA 不直接打开硬件。速度环参数已固件固定为 `Kp=0.8`、`Ki=0.1`、`Kd=0`，网页不再提供速度环调参控件。

## 通道顺序

桥接程序向 VOFA 输出纯数字 CSV，每帧以换行结尾：

```text
time_ms,
rpmA,rpmB,rpmC,rpmD,
targetA,targetB,targetC,targetD,
pwmA,pwmB,pwmC,pwmD,
battery_mV,
gyro_z_dps,target_yaw_rate_dps,yaw_output_rpm,yaw_deg,gyro_raw_dps,
target_heading_deg,heading_deg,heading_output_dps,heading_error_deg
```

VOFA 使用从 `I0` 开始的通道编号：

- `I0` 时间（ms）
- `I1-I4` 四轮实测 RPM：A 右后、B 左后、C 右前、D 左前
- `I5-I8` 四轮目标 RPM：A 右后、B 左后、C 右前、D 左前
- `I9-I12` 四轮 PWM 百分比：A 右后、B 左后、C 右前、D 左前
- `I13` 电池电压（mV）
- `I14` 滤波后实际 Z 轴角速度（°/s）
- `I15` 目标角速度（°/s）
- `I16` 角速度环输出的旋转轮速分量（RPM）
- `I17` 积分得到的相对航向角（°）
- `I18` 零偏修正后、低通滤波前的 Z 轴角速度（°/s）
- `I19` 航向角外环目标航向（°）
- `I20` 航向角外环实际航向（°）
- `I21` 航向角外环输出的目标角速度（°/s）
- `I22` 航向角误差（°）

对比单轮速度时，例如 A 轮使用 `I1`（实际）和 `I5`（目标）。
观察角速度环时，使用 `I14`（实际）、`I15`（目标）和 `I16`（PI 输出）。角速度 PI 已固定为 `Kp=0.15`、`Ki=2.5`，不使用前馈。
整定航向角外环时，使用 `I19`（目标航向）、`I20`（实际航向）、`I21`（外环输出）和 `I22`（航向误差）。航向 PD 参数已固定为 `Kp=5.0`、`Kd=1.25`，最大修正角速度为 `80 °/s`。网页“波形自动测试”的“折线路径”会在持续直行时发送 `HEADSTEP` 航向目标阶跃，并等待 `I22` 和实际角速度连续三帧收敛后进入下一段。

“0°抗扰保持”用于静止外力扰动测试。建议先设置 `10 s`：开始后 `I19` 应保持 `0°`；手动转动车体时 `I20` 偏离、`I22` 出现反向误差、`I21` 给出纠正角速度；松手后观察 `I20` 是否回到接近 `0°`，同时 `I22` 和 `I21` 是否衰减。测试不会因误差归零提前结束，结束或中止时自动发送 `STOP`。实际恢复效果需烧录后在地面实测确认。

`8088` 是网页 HTTP 端口，VOFA 必须连接 `1347`。桥接窗口需要保持运行。
