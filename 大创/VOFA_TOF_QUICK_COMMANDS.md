# VOFA 直连调试 ToF 跟踪

直接打开 VOFA+，不启动网页上位机或桥接。串口选电脑端蓝牙USB串口（本次 COM12），115200 / 8N1 / 无流控，数据引擎选 FireWater。串口连接后不会自动产生曲线，需要发送下面的 FDBG 命令。命令按文本发送，每条末尾加换行（CRLF 或 LF），不要启用十六进制发送。

## 快捷命令

| 发送文本 | 作用 |
|---|---|
| `STOP` | 停车并锁定手柄，调P前先发送 |
| `FP,0.06,0.18` | 设置前进P、后退P；立即返回实际参数 |
| `FP` | 读取参数，返回 `FP,0.0600,0.1800` |
| `FD,500` | 设置跟随距离500 mm，并返回实际值；范围100～2000 mm |
| `FD` | 查询当前跟随距离，例如 `FD,500` |
| `FDBG,1` | 开启5 Hz距离曲线，暂停其他周期遥测 |
| `FDBG,0` | 关闭距离曲线 |
| `DISARM` | 解除电机使能 |

可在VOFA命令栏配置上述快捷键。典型调试步骤：发送STOP → 发送FP/FD命令 → FDBG,1 → 手柄回中，重新按START、再按L1。R1/摇杆退出跟踪；SELECT停车。这里不提供自动ARM或运动命令。

例如只把后退P调到0.24，发送 `FP,0.06,0.24`。单位RPM/mm，两个值均限0～1。运行中修改会返回 `ERR,FP,STOP_FIRST`；需要先STOP。参数在RAM中保留，STOP、R1和再次L1不会重置，断电/复位恢复程序默认0.06/0.18。不在VOFA调试命令中写Flash。

后退默认P是前进的3倍：默认500 mm目标、200 mm实际距离、50 mm死区时，稳态请求从前进同系数的−15 RPM变为−45 RPM；最终请求仍受±80 RPM及60 RPM/s加速限制。增益是初值，尚未做落地调参验收。

## 曲线通道

MCU直接输出FireWater文本：`follow:当前目标mm,实际mm,滤波mm,误差mm,前后RPM,有效位,模式,MCU毫秒`。

| 通道（从0开始） | 含义 |
|---|---|
| CH0 | 当前目标距离，默认500 mm，FD修改后同步变化 |
| CH1 | ToF原始实际距离，mm |
| CH2 | 跟踪控制使用的滤波距离，mm |
| CH3 | 滤波距离−目标，mm；无有效滤波时为0 |
| CH4 | 前后速度请求，RPM；正前进，负后退 |
| CH5 | ToF原始测距有效位，0/1 |
| CH6 | 0关闭、1跟踪、2搜索 |
| CH7 | MCU时间，ms |

看距离时先只勾选CH0/CH1，需要时加CH2；隐藏时间CH7以免拉大纵轴。无效原始/滤波距离用−1表示，不能当成到达0 mm。未启动跟踪时，仍可看到目标与原始测距；CH2为−1。该5 Hz流用于调试趋势，并非高频PID验收记录。不会启用原88 KiB RAM日志。

串口同一时刻只能被一个程序使用；若网页/桥接或其他串口助手占用，先断开它，再用VOFA直连。FDBG上电默认关闭；TEL/ATEL/TOF流开关会退出FDBG模式，需要重新FDBG,1。

## 调整跟随距离

先发STOP，再发 `FD,500`（或 `FD,600` 等整数mm），回包就是实际目标值。输入限100～2000 mm；小数、越界、额外字段及可能溢出的长数字均拒绝。运行中设置返回 `ERR,FD,STOP_FIRST`，查询FD可随时发送。距离设定在RAM中保留，STOP、R1、重新START/L1不重置，断电/复位恢复500 mm。FP独立P参数的使用不变。

跟随模式不再因有效距离<=100 mm停车锁定，近距仍参与反馈并请求后退；有效近距不会被大距离突变规则当作目标丢失。无效/过期测距仍先清零前后请求，原有失效/超时/手柄/IMU停机保留。独立前进防撞限幅仍保持，手动模式未修改。
