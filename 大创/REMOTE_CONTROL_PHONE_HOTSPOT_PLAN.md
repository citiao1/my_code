# 车载手机热点远程遥控与图传方案

## 1. 当前确定方案

本阶段采用车载手机热点为香橙派提供互联网连接，香橙派连接摄像头并通过串口控制 STM32F407。

```text
车载手机
  └── 4G/5G 热点
          │ Wi-Fi
       香橙派
       ├── 罗技 USB 摄像头
       ├── 手机网页上位机
       ├── 视频图传服务
       └── UART
              │
          STM32F407
          ├── 四轮麦轮运动学
          ├── 四轮速度环
          ├── 角速度环
          ├── 编码器和陀螺仪
          └── 安全停车
```

车载手机只负责提供移动网络，不负责电机控制。远程操作者使用另一台手机或电脑访问车载香橙派。

## 2. 远程连接方式

原型阶段使用 Tailscale 建立车端和操作者之间的虚拟网络：

1. 车载手机开启热点，并保持移动数据可用。
2. 香橙派自动连接该热点。
3. 香橙派安装并登录 Tailscale。
4. 遥控手机或电脑安装 Tailscale，并登录同一账号。
5. 香橙派获得一个固定的 Tailscale 虚拟地址或 MagicDNS 名称。
6. 遥控端通过浏览器打开香橙派上的网页服务。

示例访问形式：

```text
http://100.x.y.z:8088
```

局域网调试时，也可以直接访问车载热点分配给香橙派的地址，例如：

```text
http://192.168.43.xxx:8088
```

局域网地址只适合近距离调试，远距离访问使用 Tailscale 地址。

## 3. 香橙派职责

- 自动连接车载手机热点。
- 运行网页上位机和 WebSocket 服务。
- 读取罗技 USB 摄像头。
- 对视频进行编码并通过 WebRTC 或等效低延迟方式传输。
- 接收网页双摇杆数据。
- 将车辆目标量通过 UART 发送给 STM32。
- 接收 STM32 遥测数据并转发到网页和 VOFA。
- 处理网络断开、串口断开和程序自动重启。

USB 摄像头通常使用 Linux UVC 驱动，设备一般会显示为 `/dev/video0`。正式确定分辨率和编码格式前，需要使用 `v4l2-ctl --list-formats-ext` 检查实际支持情况。

## 4. 香橙派与 STM32 串口

USB 口优先留给摄像头，香橙派使用 GPIO 排针上的硬件 UART：

```text
香橙派 UART_TX  -> STM32 UART_RX
香橙派 UART_RX  <- STM32 UART_TX
香橙派 GND      <-> STM32 GND
```

要求：

- 两边使用 3.3 V TTL 电平。
- TX 与 RX 交叉连接。
- 不把 5 V 接到串口信号脚。
- 在香橙派系统中启用对应 UART。
- 关闭该 UART 上的 Linux 串口控制台，避免启动日志混入控制协议。
- 初始串口参数使用 `115200, 8N1`。
- UART 物理引脚必须以实际香橙派型号的官方 Pinout 为准，不能仅凭树莓派引脚编号接线。

如果继续保留 BLE，则不能让香橙派和 BLE 同时连接到同一个 STM32 RX。可以为香橙派分配另一个 USART，也可以让香橙派取代 BLE 作为网络通信入口。

## 5. 控制协议

建议香橙派与 STM32 之间使用简洁的文本协议进行第一版验证：

```text
DRV,vx,vy,wz
STOP
CALIB_GYRO
STATUS
```

其中：

- `vx`：车体前后目标量。
- `vy`：车体左右目标量。
- `wz`：目标角速度。
- 三个量允许同时存在，支持平移和原地旋转同时进行。

后续可以改为带帧头、长度、序号和 CRC 的二进制协议，但不能改变 STM32 的安全策略。

## 6. 必须保留的安全机制

- 香橙派以 20~50 Hz 发送控制帧和心跳。
- STM32 超过约 300 ms 没有收到有效控制帧时自动停车。
- 网络恢复后不能自动恢复旧目标，必须收到新的摇杆数据。
- 视频线程堵塞不能阻塞串口控制线程。
- 香橙派重启、摄像头掉线或 UART 异常时，STM32仍然可以独立停车。
- 车体保留物理急停开关。
- 电机电源和香橙派电源使用稳定的独立降压供电，并做好滤波。

## 7. 原型验证顺序

1. 香橙派连接车载手机热点并设置自动重连。
2. 香橙派通过 GPIO UART 与 STM32 单独收发测试。
3. 验证 `STOP` 和通信超时停车。
4. 验证网页双摇杆能够发送 `vx/vy/wz`。
5. 验证 STM32 可以同时执行平移和旋转。
6. 接入罗技 USB 摄像头，确认 `/dev/video0` 和支持的格式。
7. 先完成局域网低延迟图传。
8. 配置 Tailscale，验证远程手机或电脑访问网页。
9. 测试远程网络抖动、断网、重连和视频卡顿时的车辆安全状态。

## 8. 后续正式化方向

手机热点方案用于原型验证。长期运行时建议替换为工业 4G 路由器，避免车载手机发热、断电和人为误操作。

正式版本可以使用：

```text
工业4G路由器 + 香橙派 + 罗技摄像头 + WebRTC + 公网服务器
```

香橙派与 STM32 的串口协议、网页控制逻辑和安全停车逻辑应尽量保持不变。
