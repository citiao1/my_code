# 手柄 ToF 可调距离跟踪（默认500 mm，R26功能扩展）

## 操作

- 先将摇杆回中，按 START 解锁手柄。L1 本身不能 ARM。
- 摇杆回中后重新按下 L1：开启跟踪，目标距离默认500 mm，可先STOP再通过VOFA的FD命令修改。
- R1：关闭跟踪，恢复手动；任何摇杆偏离死区也会退出并交回手动。R1 与 L1 同时按下时 R1 优先。
- SELECT、原有 START 停机、网页 STOP/DISARM、手柄无效/超时、速度环或 IMU 故障仍能终止自动运动。持续按住 L1 不会自动重启跟踪。
- 搜索满 16 秒、ToF 硬件故障、搜索偏离中心超过 55°或调度异常：停车并锁定手柄。需要回中、重新按 START，再释放/按下 L1 才能再次跟踪。
- OLED 底行 F:0=未跟踪，F:1=距离跟踪，F:2=搜索。该字段原来固定显示 1，现在显示实际模式。

## 控制及边界

单个 DL1B/VL53L1X 是单束距离反馈，不能辨认人/物体身份，也不能测量目标方位。前方有效表面距离大于0且不超过2000 mm，连续 3 帧测距差不超过 120 mm，才视作可跟踪目标；可能误认其他物体。

距离外环采用独立 P 控制，e=filtered_mm-当前目标（默认500 mm）：误差绝对值 <=50 mm 输出0；其余为 Kp*(e-sign(e)*50) RPM（前进Kp=0.06，后退Kp=0.18），限幅±80 RPM，允许倒车，增速限60 RPM/s。前进Kp与滤波不变，实际速度随距离误差变化；默认500 mm目标时，1.6 m对应63 RPM，2 m会限制到80 RPM。参数未经实车跟踪整定。

跟踪专用滤波：3点中值 + 时间常数80 ms的一阶低通，只对新的测距样本更新。已有 ToF 33 ms预算/40 ms周期、100 mm防撞及手动模式的无效测距策略均未改变。独立前进防撞限幅直接使用原始有效测距；跟随中的100 mm停车锁定按用户要求移除，保留近距后退反馈。

测距失效/超过120 ms/超过2 m/与当前滤波值突变超过400 mm时，立即将自动前后目标清零；首次观察到丢失即记录当时车身yaw，连续120 ms无法恢复后围绕该固定角度搜索，不以确认结束时的yaw重新居中。硬件未连接或未就绪直接停机。搜索目标为中心±45°，角速度请求限25°/s，边界前0.5°换向，保留10°异常偏离裕量（偏离中心超过55°锁定停车）。搜索中禁止前后运动，连续3帧一致回波确认后停止搜索；至少等待250 ms且实测角速度 <=5°/s才恢复距离运动。16秒截止不会被零星回波延长。重新捕获后再次丢失会记录新的中心角。

原速度PI、角速度PI、方向PD及保护保持原参数；不增加任何周期串口回传，不重新启用高频RAM日志。新增功能使用非阻塞状态机，不增加I2C轮询、延时或中断工作。
