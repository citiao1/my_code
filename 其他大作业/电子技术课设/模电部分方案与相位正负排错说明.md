# 李萨如图形发生器：模电部分方案与排错说明

## 1. 当前数字部分的确定输出

数字部分已经规划为：

```text
555：12 kHz 主时钟
第一片 74LS161：Q0=6 kHz，Q1=3 kHz
第二片 74LS161：模3分频，得到 4 kHz
```

模电部分只接下面两路：

```text
3 kHz 方波（第一片161的 Q1）
4 kHz 方波（第二片161的模3输出）
```

最终目标为：

```text
示波器 A（X轴）：3 kHz，幅度保持不变
示波器 B（Y轴）：4 kHz，幅度为 A 的 2 倍
频率比：fA:fB = 3:4
幅度比：B/A = 2
相位：其中一路相移 45°，建议移相 3 kHz 路
```

频率比 `3:4` 决定四叶李萨如图形；幅度比 `B/A=2` 决定图形的纵横尺寸。二者不要混淆。

## 2. 两路正弦波产生

两路方波都先经过 PPT 所示的二阶有源低通滤波器（LM324），再进行后级处理。每一路的滤波器输出应先单独确认：

```text
3 kHz 路：输出频率约 3.00 kHz，波形接近正弦
4 kHz 路：输出频率约 4.00 kHz，波形接近正弦
```

滤波器的具体拓扑必须以 PPT 原图为准：

```text
RC 二阶网络接运放同相端（+）
反馈电阻网络接运放反相端（−）
```

若使用的是单电源，滤波器的交流参考点应使用同一个 `Vref`；若使用 `+12 V/-12 V` 双电源，交流参考点可接 0 V 地。

## 3. 3 kHz 路：相位移 45°，幅度不再改变

建议在 3 kHz 低通滤波器之后加一阶全通移相器。使用 LM324 的一组运放（以 A 组为例）：

```text
1脚 = 输出
2脚 = 反相输入（−）
3脚 = 同相输入（+）
```

一种标准接法如下：

```text
3 kHz 滤波输出 ── Rin ──→ 2脚（−）
1脚输出 ───────── Rf ──→ 2脚（−）
3 kHz 滤波输出 ── Cφ ──→ 3脚（+）
3脚（+）────────── Rφ ──→ GND 或 Vref
```

取 `Rin=Rf`，全通电路的幅度理论上约为 1，不应明显放大或衰减。相位由 `Rφ Cφ` 决定。对于 `3 kHz`、`Cφ=10 nF`，可以先用 `Rφ=2.2 kΩ`，再用电位器微调。

不同软件符号可能把 RC 支路画在上方或下方，判断标准不是“上面/下面”，而是：

```text
RC 支路接运放“+”端
Rin、Rf 反馈支路接运放“−”端
```

### 3 kHz 相位的正确测量

不能把 3 kHz 和 4 kHz 两个不同频率直接用固定时间差判断相位。应测全通移相器的同频输入和输出：

```text
输入：3 kHz 滤波器输出
输出：移相器输出
```

3 kHz 周期：

```text
T = 1/3000 ≈ 333.3 μs
```

45°对应：

```text
Δt = T/8 ≈ 41.7 μs
```

必须比较两个波形的同方向过零点（例如都从负向正穿越 0 V）。实测 `39 μs` 对应约 `42°`，已经接近目标；调节 `Rφ` 使时间差接近 `41.7 μs`。

## 4. 4 kHz 路：幅度放大 2 倍，保持正极性

不要用反相放大器做 `-2`，因为会额外翻转 180°。使用 LM324 的非反相放大器，保持 4 kHz 波形正负方向不变。

以 LM324 的 B 组为例：

```text
5脚 = 同相输入（+）
6脚 = 反相输入（−）
7脚 = 输出
```

接线：

```text
4 kHz 滤波输出 ─────────→ 5脚（+）
7脚输出 ── Rf=10 kΩ ──→ 6脚（−）
6脚（−）── Rg=10 kΩ ──→ GND 或 Vref
```

非反相增益：

```text
Av = 1 + Rf/Rg = 1 + 10k/10k = 2
```

因此：

```text
4 kHz 输出峰峰值 = 原滤波输出峰峰值的约 2 倍
4 kHz 输出极性与输入相同
```

如果 4 kHz 放大后顶部削顶，不要继续增大电源或反馈增益；先降低两路滤波器输入幅度，或把 3 kHz 路衰减到 0.5 倍。当前要求是 `B/A=2`，并不要求 B 路一定放大，只要求最终幅度比正确。

## 5. 正负极性和直流偏置

### 推荐：LM324 使用双电源

若要让波形真正围绕 0 V 正负摆动，推荐：

```text
LM324 4脚 → +12 V
LM324 11脚 → −12 V
```

此时各级交流参考点接 GND。示波器两个通道的地夹也接同一个电路 GND。

### 单电源时

若 LM324 只有 `+5 V/GND`，输出不能低于 0 V，波形必须围绕 `Vref=2.5 V` 摆动：

```text
Vref：+5 V 经 10 kΩ/10 kΩ 分压得到 2.5 V
```

3 kHz 路和 4 kHz 路必须使用同一个 Vref。耦合电容后的偏置电阻、滤波器的交流参考、放大器的 Rg 下端，都不能一路接 GND、一路接 Vref，否则两路会出现上下偏置不同。

如果只是观察交流波形，可以把示波器通道改为 AC 耦合；但做 X-Y 李萨如图时，两路直流参考必须一致。

## 6. 最终示波器接法

```text
示波器 A（X）：3 kHz 移相 45°后的输出
示波器 B（Y）：4 kHz 非反相放大 2 倍后的输出
```

X-Y 模式下检查：

```text
fA ≈ 3 kHz
fB ≈ 4 kHz
Vpp(B)/Vpp(A) ≈ 2
```

若图形上下或左右翻转：

```text
先确认 A、B 的探头正端和地端没有接反；
再确认 4 kHz 放大器是“非反相”接法；
不要用额外的反相器随意补救，因为它会再增加 180°相位。
```

## 7. 给排错 AI 的重点问题

请按以下顺序判断，不要同时修改多个模块：

1. 在滤波器输入端确认 3 kHz 和 4 kHz 是否正确。
2. 在两路滤波器输出端确认波形是否接近正弦、是否削顶。
3. 对 3 kHz 移相器测输入/输出同频相位，目标 `Δt≈41.7 μs`。
4. 对 4 kHz 非反相放大器测增益，目标 `Vout/Vin≈+2`。
5. 最后再接 X-Y：A 接 3 kHz，B 接 4 kHz，检查 `B/A≈2`。

任何“起飞”、收敛错误或上下偏置异常，优先检查：运放电源脚、共地/Vref、反馈电阻是否接到了正确的 `−` 端，以及示波器地夹是否接到同一参考点。
