# 入团申请 PPT 模板填充版式选择

目标：严格复用红色党政风模板的原生版式，只替换文字内容，不引入废案中的旧视觉设计。

| 输出页 | 选用模板页 | 版式理由 |
| --- | --- | --- |
| P01 封面 | 模板第 1 页 | 大标题红色主视觉，适合作为入团申请答辩封面。 |
| P02 目录 | 模板第 2 页 | 四段式目录结构清晰，对应申请动机、个人表现、实践经历、未来计划。 |
| P03 个人基本情况 | 模板第 3 页 | 大编号 + 右侧说明，适合做第一章节开场。 |
| P04 个人画像 | 模板第 4 页 | 四宫格信息卡，适合展示班级、学习、职责、态度。 |
| P05 学习与科创实践 | 模板第 8 页 | 大编号 + 右侧说明，作为第二章节承接。 |
| P06 实践与成长路径 | 模板第 9 页 | 五节点路径结构，适合把学习、竞赛、实验室、服务、标准串成成长链路。 |
| P07 对共青团的认识与计划 | 模板第 10 页 | 主标题 + 关键词 + 说明区，适合表达核心认识和入团后承诺。 |
| P08 致谢 | 模板第 11 页 | 原模板结束页，保留正式汇报收束感。 |
