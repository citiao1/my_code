# 微机原理填空题与选择题考点总结

## 8086/8088 微处理器基础

- 8086 内部由 EU 和 BIU 两部分组成；EU 负责指令执行，BIU 负责取指、形成物理地址和总线操作。 填空常考 EU/BIU 名称与功能；选择常考哪个部件含段寄存器、IP 和指令队列。

- 8086 有 20 根地址线，可寻址 1MB 存储空间；内部数据通路 16 位，8088 外部数据总线 8 位。 填空常考 20 位、1MB、16 位/8 位差异。

- 通用寄存器 AX、BX、CX、DX 可拆成 AH/AL、BH/BL、CH/CL、DH/DL；SP、BP、SI、DI 常参与寻址。 选择常考哪个寄存器默认与 SS 或 DS 配合。

- 标志寄存器常考 CF、ZF、SF、OF、PF、AF、IF、DF、TF；算术比较后依据 ZF/CF/SF/OF 判断转移。 填空常考各标志含义；选择常考无符号/有符号条件转移依据。

- 物理地址 = 段地址 x 16 + 偏移地址；代码取指默认 CS:IP，堆栈默认 SS:SP。 几乎必考计算题/选择题，也常变成填空。

## 存储器与地址译码

- 存储器容量通常由地址线数和数据位宽确定：2^n 个单元，每单元 m 位，总容量为 2^n x m bit。 填空常考容量换算、芯片数量、地址范围。

- 地址译码方法包括全译码、部分译码和线选法；全译码无地址重叠，部分译码可能产生镜像地址。 选择常考译码方式优缺点。

- 片选信号由高位地址译码产生，低位地址接芯片内部地址端；字扩展增容量，位扩展增字长。 填空常考“字扩展/位扩展”的作用。

- 8086 存储器按偶地址存储体和奇地址存储体组织，A0 与 BHE 配合选择低/高字节。 选择常考字节/字访问时 A0、BHE 状态。

- SRAM 速度快、无需刷新；DRAM 集成度高、需刷新；ROM/EPROM/EEPROM/Flash 属于非易失存储。 选择常考存储器类型特性。

## 指令系统与寻址方式

- 立即寻址的操作数在指令中；寄存器寻址操作数在寄存器中；直接寻址给出有效地址。 填空常考寻址方式名称。

- 寄存器间接、基址、变址、基址变址寻址常由 BX/BP/SI/DI 形成有效地址；使用 BP 默认段寄存器为 SS。 选择常考默认段寄存器。

- MOV 两操作数不能同时为存储器；CS 不能作为普通目的寄存器直接装入立即数；段寄存器装载有约束。 选择常考非法指令。

- CMP 只影响标志位不保存结果；TEST 做逻辑与并影响标志位；LEA 取有效地址而不是取内存内容。 选择常考指令功能辨析。

- CALL/RET 通过堆栈保存和恢复返回地址；PUSH 先修改 SP 再写栈，POP 先读栈再修改 SP。 填空常考堆栈方向、SP 变化。

## 汇编语言程序设计

- DB、DW、DD 分别定义字节、字、双字数据；DUP 用于重复定义存储单元。 填空常考伪指令含义和存储字节数。

- SEGMENT/ENDS 定义段，ASSUME 建立段寄存器与段名关系，ORG 设置偏移地址，EQU 定义符号常量。 选择常考伪指令作用。

- 顺序、分支、循环和子程序是汇编程序的基本结构；LOOP 指令隐含使用 CX/ECX 作为计数器。 填空常考 LOOP 与 CX。

- 子程序调用应保护现场，常用 PUSH/POP 保存会被修改的寄存器。 程序题和选择题常考现场保护。

- DOS/BIOS 中断调用需要按功能号设置寄存器，例如 INT 21H 常由 AH 指定功能。 选择常考中断调用入口参数。

## 中断系统

- 中断向量表位于内存最低 1KB，每个中断向量 4 字节，内容为中断服务程序入口的 IP 和 CS。 填空高频：位置、大小、4 字节、类型码 x 4。

- 8086 中断源包括内部中断、外部 NMI、外部 INTR 和软件 INT n；NMI 不可屏蔽，INTR 受 IF 控制。 选择常考可屏蔽/不可屏蔽。

- 中断响应过程通常包括关中断、保护 FLAGS/CS/IP、转入服务程序；IRET 恢复 IP、CS、FLAGS。 填空常考入栈/出栈内容。

- 8259A 使用 IRR、ISR、IMR 管理请求、服务和屏蔽；EOI 用于结束中断服务。 选择常考三个寄存器含义。

- 中断优先级、屏蔽方式和级联方式是 8259A 的常见配置考点。 可能选择题考工作方式。

## 总线技术

- 总线按功能分为地址总线、数据总线和控制总线；地址总线宽度决定可寻址空间。 填空常考三类总线。

- 8086 最小模式由 CPU 直接产生控制信号；最大模式需总线控制器配合，适合多处理器系统。 选择常考最小/最大模式差异。

- ALE 用于锁存复用地址/数据线上的地址信息；RD、WR 控制读写；DEN 和 DT/R 控制数据收发器。 填空常考控制信号功能。

- READY 用于插入等待周期；HOLD/HLDA 用于总线请求和响应。 选择常考慢速外设/存储器如何配合。

- 典型总线周期包括 T1、T2、T3、T4，必要时插入 Tw 等待状态。 填空常考总线时序阶段。

## 接口芯片与 I/O

- I/O 端口有独立编址和统一编址两种方式；8086 使用 IN、OUT 指令访问独立编址端口。 选择常考 I/O 编址方式。

- 8255A 有 A、B、C 三个端口，C 口可分上下半部，工作方式包括方式 0、方式 1、方式 2。 填空常考端口数量和方式编号。

- 8255A 控制字最高位 D7=1 表示方式选择控制字，D7=0 表示 C 口按位置位/复位控制字。 选择常考控制字判别。

- 8253/8254 是可编程定时/计数器，通常含 3 个独立计数通道，每个通道 16 位计数。 填空常考通道数、位数和计数初值。

- 并行接口重在多位同步传输，串行接口重在逐位传输；握手信号用于协调 CPU 与外设速度。 选择常考并行/串行和查询/中断/DMA 方式。
