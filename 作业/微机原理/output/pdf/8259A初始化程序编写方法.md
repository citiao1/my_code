# 8259A 初始化程序编写方法

资料依据: `中断.pdf` 中 7.3 节“中断控制器 8259A”，重点对应 8259A 的编程、ICW1-ICW4、OCW1、EOI 和课件例题。

## 一、先记住初始化程序的固定骨架

8259A 初始化不是随便写 `OUT`，而是按照 ICW 的顺序写入。

单片 8259A 且需要 ICW4 时，最常见骨架是:

```asm
; 设 8259A 的偶地址端口为 PORT0，奇地址端口为 PORT1
MOV AL, ICW1
OUT PORT0, AL
MOV AL, ICW2
OUT PORT1, AL
MOV AL, ICW4
OUT PORT1, AL
MOV AL, OCW1
OUT PORT1, AL
```

如果是级联方式，还要在 ICW2 与 ICW4 之间增加 ICW3:

```asm
MOV AL, ICW1
OUT PORT0, AL
MOV AL, ICW2
OUT PORT1, AL
MOV AL, ICW3
OUT PORT1, AL
MOV AL, ICW4
OUT PORT1, AL
MOV AL, OCW1
OUT PORT1, AL
```

公式: 偶端口写 ICW1 和 OCW2/OCW3，奇端口写 ICW2、ICW3、ICW4、OCW1。

## 二、从题目条件提取 6 个变量

做 8259A 初始化题，先把题目翻译成下面 6 个变量:

1. 端口地址: 偶地址端口 `PORT0`，奇地址端口 `PORT1`。
2. 单片还是级联: 单片则 `SNGL=1`，级联则 `SNGL=0` 并要写 ICW3。
3. 触发方式: 电平触发 `LTIM=1`，边沿触发 `LTIM=0`。
4. 是否使用 8086/8088 模式: 8086/8088 模式通常 `uPM=1`，因此 ICW1 的 `IC4=1`，需要 ICW4。
5. 中断类型码基值: 题目常说“IR0 的中断类型码为 xxH”，这个值直接作为 ICW2。
6. 屏蔽哪些 IR 输入: 屏蔽 IRi 就令 OCW1 的 Di=1，不屏蔽则 Di=0。

把这 6 项填完，初始化程序基本就写完了。

## 三、ICW1 的公式

ICW1 写入偶端口，且 D4 必须为 1，表示正在写初始化命令字。

位定义:

| 位 | 名称 | 取值规则 |
|---|---|---|
| D7-D5 | A7-A5 | 8086/8088 系统中不用，通常写 000 |
| D4 | 固定标志 | 固定为 1 |
| D3 | LTIM | 电平触发为 1，边沿触发为 0 |
| D2 | ADI | 8086/8088 中不用，通常写 0 |
| D1 | SNGL | 单片为 1，级联为 0 |
| D0 | IC4 | 需要 ICW4 为 1，不需要为 0 |

计算公式:

```text
ICW1 = 10H + LTIM*08H + SNGL*02H + IC4
```

常见情况:

| 条件 | ICW1 二进制 | ICW1 十六进制 |
|---|---:|---:|
| 单片、边沿触发、需要 ICW4 | 00010011B | 13H |
| 单片、电平触发、需要 ICW4 | 00011011B | 1BH |
| 级联、边沿触发、需要 ICW4 | 00010001B | 11H |
| 级联、电平触发、需要 ICW4 | 00011001B | 19H |

课件例题中“单片、电平触发、要 ICW4”，所以:

```text
ICW1 = 10H + 08H + 02H + 01H = 1BH
```

对应程序:

```asm
MOV AL, 1BH
OUT PORT0, AL
```

## 四、ICW2 的公式

ICW2 写入奇端口，用来设置中断类型码的高 5 位。

在 8086/8088 系统中，一个 8259A 管理 8 个中断源，IR0-IR7 的类型码连续排列:

```text
IR0 类型码 = ICW2
IR1 类型码 = ICW2 + 1
...
IRi 类型码 = ICW2 + i
...
IR7 类型码 = ICW2 + 7
```

如果题目直接给“IR0 的中断类型码为 38H”，则:

```text
ICW2 = 38H
```

对应程序:

```asm
MOV AL, 38H
OUT PORT1, AL
```

如果题目给的是“IR5 的中断类型码为 1BH”，则先反推:

```text
ICW2 = 1BH - 5 = 16H
```

但要注意 8259A 的 8 个类型码应按 8 对齐，ICW2 的低 3 位在 8086/8088 中通常无效或应理解为 0。因此考试题若给“IR0 类型码”，最稳；若给 IRi 类型码，需要看题目和教材约定，一般按连续类型码反推基值。

## 五、ICW3 的公式

只有级联时才写 ICW3。单片时不写 ICW3。

主片 ICW3:

```text
如果主片 IRi 接有从片，则 Di=1；否则 Di=0。
```

例: 从片接在主片 IR3 和 IR6:

```text
ICW3(主片) = 01001000B = 48H
```

从片 ICW3:

```text
写入该从片连接到主片的 IR 编号。
```

例: 某从片接在主片 IR3:

```text
ICW3(从片) = 00000011B = 03H
```

例: 某从片接在主片 IR6:

```text
ICW3(从片) = 00000110B = 06H
```

级联系统写程序时，主片和每个从片都要分别初始化。

## 六、ICW4 的公式

ICW4 写入奇端口。只要 ICW1 的 D0=1，就必须继续写 ICW4。

位定义:

| 位 | 名称 | 取值规则 |
|---|---|---|
| D7-D5 | 固定 | 通常为 000 |
| D4 | SFNM | 特殊全嵌套为 1，普通全嵌套为 0 |
| D3 | BUF | 缓冲方式为 1，非缓冲方式为 0 |
| D2 | M/S | 缓冲方式下主片为 1，从片为 0；非缓冲方式通常为 0 |
| D1 | AEOI | 自动 EOI 为 1，普通/正常 EOI 为 0 |
| D0 | uPM | 8086/8088 模式为 1，MCS-80/85 模式为 0 |

计算公式:

```text
ICW4 = SFNM*10H + BUF*08H + MS*04H + AEOI*02H + uPM
```

最常见条件是“普通完全嵌套方式、非缓冲方式、普通 EOI、8086/8088 模式”，所以:

```text
ICW4 = 01H
```

如果题目说“自动 EOI”，则:

```text
ICW4 = 01H + 02H = 03H
```

如果题目说“特殊全嵌套”，则:

```text
ICW4 = 01H + 10H = 11H
```

课件例题为“普通全嵌套、非缓冲、正常 EOI”，所以:

```asm
MOV AL, 01H
OUT PORT1, AL
```

## 七、OCW1 的公式

OCW1 是中断屏蔽字，写入奇端口。

规则非常直接:

```text
屏蔽 IRi -> Di = 1
允许 IRi -> Di = 0
OCW1 = D7D6D5D4D3D2D1D0
```

例: 屏蔽 IR1 和 IR5:

```text
D5=1, D1=1，其余为 0
OCW1 = 00100010B = 22H
```

例: 屏蔽 IR3 和 IR7:

```text
D7=1, D3=1，其余为 0
OCW1 = 10001000B = 88H
```

对应程序:

```asm
MOV AL, 22H
OUT PORT1, AL
```

## 八、把题目套进模板

题型模板:

```text
已知 8259A 的端口地址为 P0H 和 P1H，系统中只有一片 8259A，
采用正常完全嵌套方式，普通 EOI 方式，中断请求高电平有效，
IR0 的中断类型码为 TH，IRa、IRb 被屏蔽。写初始化程序。
```

套用步骤:

1. 端口: `PORT0=P0H`，`PORT1=P1H`。
2. 单片: `SNGL=1`。
3. 高电平有效一般按电平触发处理: `LTIM=1`。
4. 8086/8088 模式: `IC4=1`，`uPM=1`。
5. 普通完全嵌套、普通 EOI、非缓冲: `ICW4=01H`。
6. `ICW2=TH`。
7. 屏蔽 IRa、IRb: `OCW1 = 2^a + 2^b`。

最终代码:

```asm
MOV AL, ICW1
OUT P0H, AL
MOV AL, TH
OUT P1H, AL
MOV AL, 01H
OUT P1H, AL
MOV AL, OCW1
OUT P1H, AL
```

## 九、课件例题完整拆解

题目: 设 IBM PC 机接有一片 8259A，两个端口地址为 60H、61H，管理 8 个中断源，采用普通完全嵌套方式，普通 EOI 方式，中断请求高电平有效，IR0 的中断类型号为 38H。IR1、IR5 需要被屏蔽。

拆解:

| 条件 | 推出 |
|---|---|
| 端口 60H、61H | 60H 为偶端口，61H 为奇端口 |
| 一片 8259A | SNGL=1，不写 ICW3 |
| 高电平有效 | LTIM=1 |
| 8086/8088 | IC4=1，ICW4 要写，uPM=1 |
| 普通完全嵌套 | SFNM=0 |
| 普通 EOI | AEOI=0 |
| 非缓冲方式 | BUF=0 |
| IR0 类型号 38H | ICW2=38H |
| 屏蔽 IR1、IR5 | OCW1=00100010B=22H |

计算:

```text
ICW1 = 10H + 08H + 02H + 01H = 1BH
ICW2 = 38H
ICW4 = 01H
OCW1 = 2^1 + 2^5 = 02H + 20H = 22H
```

程序:

```asm
MOV AL, 1BH
OUT 60H, AL
MOV AL, 38H
OUT 61H, AL
MOV AL, 01H
OUT 61H, AL
MOV AL, 22H
OUT 61H, AL
```

## 十、综合题中的 8259A 初始化

课件综合题给出:

```text
8259A 端口地址为 170H 和 171H；
系统中只有一片 8259A；
采用正常完全嵌套方式；
普通 EOI 方式；
中断请求高电平有效；
IR0 的中断类型码为 38H；
IR3 和 IR7 被屏蔽。
```

逐项计算:

```text
ICW1 = 单片 + 电平触发 + 要 ICW4
     = 10H + 08H + 02H + 01H
     = 1BH

ICW2 = 38H

ICW4 = 普通全嵌套 + 非缓冲 + 普通 EOI + 8086/8088
     = 01H

OCW1 = 屏蔽 IR3 和 IR7
     = 00001000B + 10000000B
     = 10001000B
     = 88H
```

初始化程序:

```asm
MOV AL, 1BH
OUT 170H, AL
MOV AL, 38H
OUT 171H, AL
MOV AL, 01H
OUT 171H, AL
MOV AL, 88H
OUT 171H, AL
```

## 十一、普通 EOI 的收尾程序

如果 ICW4 中 `AEOI=0`，表示正常/普通 EOI。中断服务程序返回前必须向 8259A 偶端口送 EOI 命令 `20H`。

模板:

```asm
MOV AL, 20H
OUT PORT0, AL
IRET
```

例: 8259A 端口为 60H、61H:

```asm
MOV AL, 20H
OUT 60H, AL
IRET
```

例: 8259A 端口为 20H、21H:

```asm
MOV AL, 20H
OUT 20H, AL
IRET
```

注意: EOI 命令不是初始化命令字，而是中断服务程序结束时发给 8259A 的操作命令。初始化程序里通常只写 ICW 和 OCW1；服务程序里才写 EOI。

## 十二、考试快速检查表

写完后按下面清单检查:

1. ICW1 是否写到了偶端口。
2. ICW2 是否写到了奇端口。
3. 单片时是否没有多写 ICW3。
4. 级联时是否写了 ICW3，并且主片和从片含义没有写反。
5. ICW1 的 D4 是否为 1。
6. 电平触发是否令 ICW1 的 D3=1。
7. 单片是否令 ICW1 的 D1=1。
8. 8086/8088 模式是否令 ICW1 的 D0=1，并继续写 ICW4。
9. 普通 EOI 是否令 ICW4 的 D1=0。
10. OCW1 是否是“屏蔽为 1，允许为 0”，不要写反。
11. 普通 EOI 的中断服务程序末尾是否 `OUT PORT0, 20H`。

最核心的一句话:

```text
先算 ICW1，再填 ICW2，单片跳过 ICW3，8086 写 ICW4，最后用 OCW1 屏蔽中断源。
```
