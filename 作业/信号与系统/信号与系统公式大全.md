# 信号与系统公式大全

整理依据：当前文件夹中的《信号与系统不挂科》1-7 讲义体系。

约定：单位阶跃函数统一记作 $u(t)$；离散单位阶跃记作 $u[n]$。

## 0. 约定与常用符号

### 单位阶跃、冲激、符号函数

> 本册把单位阶跃函数统一记作 u(t)。离散单位阶跃记作 u[n]。

- u(t)=0，t<0; 1，t>0,
- δ(t)=((d) / (dt))u(t), u(t)=∫[-∞ → t]δ(τ) dτ
- sgn(t)=2u(t)-1, u(t)=((1+sgn(t)) / (2))
- ∫[-∞ → ∞]x(t)δ(t-t_0) dt=x(t_0)

### 尺度、时移、翻转

> 先做括号内的线性变换，再观察图形位置和宽度。

- x(t-t_0): 右移 t_0, x(t+t_0): 左移 t_0
- x(at): |a|>1 压缩, 0<|a|<1 展宽
- x(-t): 关于 t=0 翻转
- δ(at)=((1) / (|a|))δ(t), u(at)=u(t)，a>0; u(-t)，a<0

### 能量、功率、内积

> 能量信号平均功率为 0；功率信号总能量一般无穷大。

- E_x=∫[-∞ → ∞]|x(t)|^2 dt
- P_x=lim[T→∞]((1) / (2T))∫[-T → T]|x(t)|^2 dt
- < x,y>=∫[-∞ → ∞]x(t)y^*(t) dt
- E_x+y=E_x+E_y+2Re< x,y>

### 奇偶分解

> 任何信号都能唯一分成偶分量和奇分量。

- x_e(t)=((x(t)+x(-t)) / (2))
- x_o(t)=((x(t)-x(-t)) / (2))
- x(t)=x_e(t)+x_o(t)

## 1. 连续时间系统的时域分析

### 线性时不变系统 LTI

> LTI 系统完全由冲激响应 h(t) 描述。

- y(t)=x(t)*h(t)
- x(t)*h(t)=∫[-∞ → ∞]x(τ)h(t-τ) dτ
- x(t)*δ(t-t_0)=x(t-t_0)
- δ(t)*h(t)=h(t)

### 由微分方程求零输入与零状态

> 总响应 = 零输入响应 + 零状态响应。

- ∑[k=0 → N]a_k((d^k y(t)) / (dt^k))
- =∑[m=0 → M]b_m((d^m x(t)) / (dt^m))
- y(t)=y_zi(t)+y_zs(t)
- y_zs(t)=x(t)*h(t)

### 阶跃输入 u(t) 与阶跃响应

> 为避免混淆：u(t) 是单位阶跃函数；s(t) 常表示系统对 u(t) 的响应。

- s(t)=h(t)*u(t)=∫[-∞ → t]h(τ) dτ
- h(t)=((d) / (dt))s(t)
- x(t)=∫[-∞ → ∞]x'(τ)u(t-τ) dτ

### 因果性、稳定性、可逆性

> 考试常用 h(t) 的支撑区间和绝对可积性判断。

- 因果 LTI: h(t)=0, t<0
- BIBO 稳定: ∫[-∞ → ∞]|h(t)| dt<∞
- 可逆: h(t)*h_i(t)=δ(t)

## 2. 连续时间傅里叶级数 CTFS

### 三角形式与指数形式

> 周期为 T，基波角频率 omega_0=2pi/T。

- x(t)=a_0+∑[n=1 → ∞][a_ncos(nω_0 t)+b_nsin(nω_0 t)]
- a_0=((1) / (T))∫_T x(t) dt
- a_n=((2) / (T))∫_T x(t)cos(nω_0t) dt
- b_n=((2) / (T))∫_T x(t)sin(nω_0t) dt
- x(t)=∑[k=-∞ → ∞]C_k e^(jkω_0t)
- C_k=((1) / (T))∫_T x(t)e^(-jkω_0t) dt

### 系数对称性

> 实信号满足共轭对称，偶/奇性可快速判断系数。

- x(t)inℝ ⇒ C_-k=C_k^*
- x(t) real even ⇒ C_kinℝ, b_n=0
- x(t) real odd ⇒ C_k pure imaginary, a_n=0

### Parseval 等式

> 周期信号的平均功率可在频域求。

- P=((1) / (T))∫_T |x(t)|^2 dt
- =∑[k=-∞ → ∞]|C_k|^2
- =a_0^2+((1) / (2))∑[n=1 → ∞](a_n^2+b_n^2)

## 3. 连续时间傅里叶变换 CTFT

### 定义与反变换

> 本册采用角频率 omega 的工程常用约定。

- X(jω)=Fx(t)
- =∫[-∞ → ∞]x(t)e^(-jω t) dt
- x(t)=F⁻¹X(jω)
- =((1) / (2π))∫[-∞ → ∞]X(jω)e^(jω t) dω

### 基本变换对

> 常用变换对建议直接背，尤其是冲激、指数、矩形、抽样函数。

- δ(t) ↔ 1
- 1 ↔ 2πδ(ω)
- e^(jω_0t) ↔ 2πδ(ω-ω_0)
- cosω_0t ↔ π[δ(ω-ω_0)+δ(ω+ω_0)]
- sinω_0t ↔ ((π) / (j))[δ(ω-ω_0)-δ(ω+ω_0)]
- e^(-at)u(t) ↔ ((1) / (a+jω)), a>0
- u(t) ↔ πδ(ω)+((1) / (jω))
- rect≤ft(((t) / (τ))) ↔ τ Sa≤ft(((ωτ) / (2)))
- Sa(t)=((sin t) / (t))

### 性质总表

> 时域操作和频域操作常成对出现。

- ax_1(t)+bx_2(t) ↔ aX_1(jω)+bX_2(jω)
- x(t-t_0) ↔ e^(-jω t_0)X(jω)
- e^(jω_0t)x(t) ↔ X[j(ω-ω_0)]
- x(at) ↔ ((1) / (|a|))X≤ft(j((ω) / (a)))
- ((d^n x(t)) / (dt^n)) ↔ (jω)^nX(jω)
- t^n x(t) ↔ j^n((d^nX(jω)) / (dω^n))
- x(t)*h(t) ↔ X(jω)H(jω)
- x(t)h(t) ↔ ((1) / (2π))X(jω)*H(jω)

### Parseval 与能量谱

> 能量谱密度为 |X(jomega)|^2。

- E=∫[-∞ → ∞]|x(t)|^2 dt
- =((1) / (2π))∫[-∞ → ∞]|X(jω)|^2 dω

## 4. 连续时间系统的频域分析

### 频率响应

> 正弦稳态中，系统只改变幅度和相位。

- H(jω)=Fh(t)
- Y(jω)=X(jω)H(jω)
- x(t)=Acos(ω_0t+φ)
- ⇒ y_ss(t)=A|H(jω_0)|
- ·cos[ω_0t+φ+∠ H(jω_0)]

### 无失真传输

> 输出只允许幅度缩放和整体延时。

- y(t)=Kx(t-t_d)
- H(jω)=K e^(-jω t_d)
- |H(jω)|=K, ∠ H(jω)=-ω t_d

### 理想滤波器

> 理想低通的冲激响应是 sinc/Sa 形状，非因果。

- H_LP(jω)=1，|ω|≤ ω_c; 0，|ω|>ω_c
- h_LP(t)=((1) / (2π))∫[-ω_c → ω_c]e^(jω t) dω
- =((sinω_c t) / (π t))=((ω_c) / (π))Sa(ω_ct)

### 采样定理

> 带限到 |omega| <= omega_m 时，采样角频率需大于两倍最高角频率。

- x_s(t)=x(t)∑[n=-∞ → ∞]δ(t-nT_s)
- X_s(jω)=((1) / (T_s))∑[k=-∞ → ∞]X[j(ω-kω_s)]
- ω_s=((2π) / (T_s)), ω_s>2ω_m
- x(t)=∑[n=-∞ → ∞]x(nT_s)
- ·Sa≤ft[ω_m(t-nT_s)] (ω_s=2ω_m)

## 5. 拉普拉斯变换与复频域分析

### 单边/双边拉普拉斯变换

> 连续因果系统常用单边拉普拉斯处理初值。

- X(s)=∫[-∞ → ∞]x(t)e^(-st) dt
- X_+(s)=∫[0^- → ∞]x(t)e^(-st) dt
- s=σ+jω

### 常用变换对

> 右边信号一般乘 u(t)，收敛域在最右极点右侧。

- δ(t) ↔ 1
- u(t) ↔ ((1) / (s)), Res>0
- e^(-at)u(t) ↔ ((1) / (s+a)), Res>-a
- t^n e^(-at)u(t) ↔ ((n!) / ((s+a)^(n+1)))
- cosω_0t u(t) ↔ ((s) / (s^2+ω_0^2))
- sinω_0t u(t) ↔ ((ω_0) / (s^2+ω_0^2))

### 性质与初终值

> 初值/终值定理使用前要检查极点条件。

- ((dx(t)) / (dt)) ↔ sX_+(s)-x(0^-)
- ∫[0^- → t]x(τ)dτ ↔ ((X_+(s)) / (s))
- x(t-t_0)u(t-t_0) ↔ e^(-st_0)X(s)
- x(0^+)=lim[s→∞]sX(s)
- x(∞)=lim[s→ 0]sX(s)

### 系统函数与稳定性

> 频率响应是系统函数在 jomega 轴上的取值，前提是 jomega 轴在 ROC 内。

- H(s)=((Y_zs(s)) / (X(s)))
- H(s)=((∑[m=0 → M]b_ms^m) / (∑[k=0 → N]a_ks^k))
- h(t)=L⁻¹H(s)
- H(jω)=H(s)|_s=jω
- 因果稳定: all poles in left half-plane

## 6. 离散时间系统的时域分析

### 基本序列

> 离散单位阶跃写作 u[n]，单位样值写作 delta[n]。

- δ[n]=1，n=0; 0，n≠0
- u[n]=1，n≥0; 0，n<0
- u[n]-u[n-1]=δ[n]
- u[n]=∑[k=-∞ → n]δ[k]

### 离散卷积

> 换元、翻转、平移、相乘、求和。

- y[n]=x[n]*h[n]
- =∑[k=-∞ → ∞]x[k]h[n-k]
- x[n]*δ[n-n_0]=x[n-n_0]
- x[n]*u[n]=∑[k=-∞ → n]x[k]

### 差分方程

> 求解思路与连续系统相同：齐次解 + 特解，或 z 域。

- ∑[k=0 → N]a_k y[n-k]=∑[m=0 → M]b_m x[n-m]
- y[n]=y_zi[n]+y_zs[n]
- y_zs[n]=x[n]*h[n]

### 离散 LTI 性质

> 判断规则与连续系统完全对应。

- 因果: h[n]=0, n<0
- BIBO 稳定: ∑[n=-∞ → ∞]|h[n]|<∞
- 可逆: h[n]*h_i[n]=δ[n]

## 7. z 变换

### 定义与反变换

> z 变换必须连同收敛域 ROC 一起看。

- X(z)=Zx[n]=∑[n=-∞ → ∞]x[n]z^(-n)
- x[n]=Z⁻¹X(z)
- z=re^(jΩ)

### 常用变换对

> 右边序列和左边序列形式相同，ROC 不同。

- δ[n] ↔ 1
- u[n] ↔ ((1) / (1-z^(-1)))=((z) / (z-1)), |z|>1
- a^n u[n] ↔ ((1) / (1-az^(-1)))=((z) / (z-a)), |z|>|a|
- -a^n u[-n-1] ↔ ((1) / (1-az^(-1))), |z|<|a|
- n a^n u[n] ↔ ((az^(-1)) / ((1-az^(-1))^2))

### z 变换性质

> 移位性质要注意初始条件；双边形式最干净。

- x[n-n_0] ↔ z^(-n_0)X(z)
- a^n x[n] ↔ X≤ft(((z) / (a)))
- n x[n] ↔ -z((dX(z)) / (dz))
- x[n]*h[n] ↔ X(z)H(z)
- x[0]=lim[z→∞]X(z) (right-sided)
- x[∞]=lim[z→1](1-z^(-1))X(z)

### 系统函数、频率响应、稳定性

> 单位圆在 ROC 内时，H(e^{jOmega}) 存在。

- H(z)=((Y_zs(z)) / (X(z)))
- H(z)=((∑[m=0 → M]b_m z^(-m)) / (1+∑[k=1 → N]a_k z^(-k)))
- H(e^(jΩ))=H(z)|_z=e^(jΩ)
- 因果稳定: all poles inside unit circle

## 8. 考前速查

### 卷积常用技巧

> 遇到阶跃函数时先把积分/求和上下限画出来。

- u(t-a)u(b-t)=1 only for a≤ t≤ b
- ∫[-∞ → ∞]f(τ)u(τ-a)u(t-τ) dτ
- =∫[a → t]f(τ) dτ (t≥ a)
- e^(-at)u(t)*e^(-bt)u(t)
- =((e^(-bt)-e^(-at)) / (a-b))u(t) (a≠ b)

### 判断系统性质

> 先看是否有时变参数、未来输入、非线性运算，再看 h。

- memoryless: y(t_0) only depends on x(t_0)
- linear: Tax_1+bx_2=aTx_1+bTx_2
- time invariant: x(t-t_0)⇒ y(t-t_0)
- causal: no future input is used

### 变换域解题路线

> 微分/差分方程优先转到 s 域或 z 域，再反变换。

- continuous: differential equation⇒ H(s)⇒ h(t),y(t)
- discrete: difference equation⇒ H(z)⇒ h[n],y[n]
- frequency response: H(jω) or H(e^(jΩ))
