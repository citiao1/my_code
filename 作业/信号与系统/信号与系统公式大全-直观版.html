1. 连续时间系统的时域分析

LTI 系统与卷积

线性时不变系统完全由冲激响应 h(t) 描述。

y(t) = x(t) * h(t)
x(t) * h(t) = ∫-∞∞ x(τ)h(t - τ)dτ
x(t) * δ(t - t0) = x(t - t0)
δ(t) * h(t) = h(t)

零输入、零状态、阶跃输入

总响应 = 零输入响应 + 零状态响应；阶跃输入统一写作 u(t)。

y(t) = yzi(t) + yzs(t)
yzs(t) = x(t) * h(t)
s(t) = h(t) * u(t)
s(t) = ∫-∞t h(τ)dτ
h(t) = d s(t)dt

因果性、稳定性、可逆性

判断 LTI 系统时，优先看 h(t)。

因果：h(t) = 0，t < 0
BIBO 稳定：∫-∞∞ |h(t)|dt < ∞
可逆：h(t) * hi(t) = δ(t)

2. 连续时间傅里叶级数 CTFS

三角形式

周期为 T，基波角频率 ω0 = 2π / T。

x(t) = a0 + Σn=1∞[ancos(nω0t) + bnsin(nω0t)]
a0 = 1T ∫T x(t)dt
an = 2T ∫T x(t)cos(nω0t)dt
bn = 2T ∫T x(t)sin(nω0t)dt

指数形式与 Parseval

实信号满足 C-k = Ck*。

x(t) = Σk=-∞∞ Ckejkω₀t
Ck = 1T ∫T x(t)e-jkω₀tdt
P = 1T ∫T|x(t)|2dt
P = Σk=-∞∞|Ck|2

3. 连续时间傅里叶变换 CTFT

定义

采用角频率 ω 的工程常用约定。

X(jω) = ∫-∞∞ x(t)e-jωtdt
x(t) = 12π ∫-∞∞ X(jω)ejωtdω

常用变换对

冲激、阶跃、指数、正余弦是最高频考点。

δ(t) ↔ 1
1 ↔ 2πδ(ω)
ejω₀t ↔ 2πδ(ω - ω0)
cos(ω0t) ↔ π[δ(ω - ω0) + δ(ω + ω0)]
sin(ω0t) ↔ πj[δ(ω - ω0) - δ(ω + ω0)]
e-atu(t) ↔ 1a + jω，a > 0
u(t) ↔ πδ(ω) + 1jω

性质

时域操作和频域操作成对出现。

x(t - t0) ↔ e-jωt₀X(jω)
ejω₀tx(t) ↔ X[j(ω - ω0)]
x(at) ↔ 1|a|X(jω/a)
dnx(t)dtn ↔ (jω)nX(jω)
x(t) * h(t) ↔ X(jω)H(jω)
x(t)h(t) ↔ 12πX(jω) * H(jω)
E = ∫-∞∞|x(t)|2dt = 12π∫-∞∞|X(jω)|2dω

5. 拉普拉斯变换与复频域分析

6. 离散时间系统的时域分析

基本序列与卷积

离散单位阶跃写作 u[n]，单位样值写作 δ[n]。

δ[n] = {
1n = 0
0n ≠ 0
u[n] = {

0n < 0
