# 实验四、五、六报告填写要点

## 实验四：零极点对过渡过程的影响

参数取 `zeta=0.5, wn=1`，所以标准二阶系统的闭环极点为
`-0.5 +/- 0.8660i`。实验中可取：

- 附加闭环极点：`T=0.2, 2, 5`，对应极点 `-5, -0.5, -0.2`。
- 附加闭环零点：`tau=0.2, 2, 5`，对应零点 `-5, -0.5, -0.2`。

报告结论可以这样写：

1. 附加极点离虚轴很远时，例如 `-5`，响应曲线与标准二阶系统接近，影响较小。
2. 附加极点靠近主导极点时，系统阶次升高后过渡过程变慢，调节时间增大。
3. 附加极点比原二阶极点更靠近虚轴时，例如 `-0.2`，它成为主导极点，响应主要表现为慢的一阶衰减，原来的共轭复极点影响退居次要。
4. 附加零点离虚轴很远时影响较小；零点靠近虚轴时会明显改变响应形状，通常使初始响应更快，但也可能增大超调或峰值。

运行 `lab4_zero_pole_effect.m` 后，图和指标表会保存在 `results_lab4_5_6` 文件夹。

## 实验五：PID 调节规律

飞机自动驾驶仪对象由两个环节串联：

`G0(s)=(-10/(s+10)) * (-(s+5)/(s^2+3.5s+6))`

即等效被控对象：

`G0(s)=10(s+5)/((s+10)(s^2+3.5s+6))`

你已经完成的 Simulink PID 选择为并行 PID：

- `P = 6`
- `I = 11`
- `D = 2`
- `N = 100`

注意：实验指导书写的是 `Kc(1 + 1/(Ti*s) + Td*s)`；而 Simulink 并行 PID 是 `P + I/s + D*s`。两者换算关系为：

- `P = Kc`
- `I = Kc/Ti`
- `D = Kc*Td`

你给出的质量指标可直接填：

- 峰值时间 `tp = 2.8570 s`
- 过渡时间 `ts = 1.8246 s`
- 最大偏差 `0.0037`
- 超调量 `0.37%`
- 稳态余差约 `0`，原始计算为 `-0.000014`
- 衰减比 `0.98`

调节规律作用：

1. 比例 P：提高比例增益可以加快响应、减小余差，但增益过大时超调和振荡会增大，甚至可能导致不稳定。
2. 积分 I：可以消除阶跃输入下的稳态余差，但积分作用过强会使系统响应变慢、超调增大，稳定裕度下降。
3. 微分 D：根据误差变化趋势提前修正，可改善动态过程、减小超调、提高阻尼；但对噪声敏感，实际使用时常配合滤波系数 `N`。

斜坡输入 `theta_d(t)=0.5t`、纯 P 控制 `Kc=2` 时，你多次调试得到的 10 s 航向角误差中，最后一次结果为 `0.0598`。报告中建议以最终确认的仿真模型输出为准；若老师要求纯 P 控制理论/固定模型结果，则需保证输入斜率、仿真时间、采样点和误差定义一致。

## 实验六：根轨迹

内容 2 的对象为：

`G(s)=K/(s^2(s+a)), a>0`

未增加开环零点时，闭环特征方程为：

`s^3 + a*s^2 + K = 0`

由 Routh 判据可知，当 `K>0` 时系统始终不稳定。

增加负开环零点 `z=-b, b>0` 后：

`G(s)=K(s+b)/(s^2(s+a))`

闭环特征方程为：

`s^3 + a*s^2 + K*s + K*b = 0`

Routh 判据给出稳定条件：

`a*K > K*b`，因此 `b < a` 时，系统可通过调节 `K` 稳定；`b > a` 时，对任意 `K>0` 仍不稳定。

你的根轨迹图中使用了 `a=2`，`b=4` 和 `b=1`：

- 原始系统：始终不稳定。
- `b=4>a=2`：始终不稳定。
- `b=1<a=2`：通过调节 `K` 系统可稳定。
