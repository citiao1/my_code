# 5 路红外传感器改 8 路 实施计划

## 一、任务摘要

将当前基于 5 路红外传感器的循迹系统扩展为 8 路，并移除冲突的 WDD35D4 角度传感器模块（释放 PA22 给第 8 路红外）。

## 二、用户确认的关键决策

### 2.1 引脚分配（从左到右 OUT1~OUT8）

| 通道 | 引脚 | 权重 | 说明 |
|------|------|------|------|
| OUT1 | PA27 | -3.5 | 原有（最左） |
| OUT2 | PA26 | -2.5 | 原有 |
| OUT3 | PA25 | -1.5 | 原有 |
| OUT4 | PA24 | -0.5 | 原有 |
| OUT5 | PB25 | +0.5 | 原有 |
| OUT6 | PB24 | +1.5 | 新增 |
| OUT7 | PB20 | +2.5 | 新增 |
| OUT8 | PA22 | +3.5 | 新增（原角度传感器 ADC 引脚） |

### 2.2 位置权重
- 权重数组：`{-3.5f, -2.5f, -1.5f, -0.5f, +0.5f, +1.5f, +2.5f, +3.5f}`
- 归一化因子：`MID_IR_WEIGHT_MAX = 3.5f`
- 输出范围：[-1, +1]，与原 5 路系统一致，下游 PID 无需改动

### 2.3 紧急停车逻辑变更（用户明确要求）

- **原 5 路逻辑**：窗口内 5 路每一路都至少识别到一次黑线（`or_mask == 0x1F`）→ 停车
- **新 8 路逻辑**：窗口内 8 路中**任意 4 路**（或更多）都至少识别到一次黑线 → 停车
- **实现方式**：计算窗口内 OR 累加掩码 `or_mask`（8 位），统计其中 1 的个数（popcount），`popcount >= 4` 即触发
- **触发阈值宏**：新增 `MID_LINE_EMG_MIN_SENSORS (4)`，便于后续调整

### 2.4 角度传感器处理
- **完全移除** WDD35D4 角度传感器功能
- PA22 从 ADC 模拟输入改为 GPIO 数字输入（OUT8）
- 清除 VOFA+ 通道 10（角度传感器），绘图通道数从 11 改为 10

### 2.5 文件编码
- 所有被修改的 .c/.h 文件目前为 GB2312 编码，修改后保持 GB2312 编码

**修改点 3：emergency 逻辑重构**（`MID_Line_CheckEmergency` 函数，第 281-320 行）

原逻辑（5 路全检测到）：
```c
if ((or_mask & 0x1FU) == 0x1FU) {  /* 5 位全 1 */
    /* 触发停车 */
}
```

新逻辑（8 路中任意 4 路检测到）：
```c
/* 统计 or_mask 中 1 的个数（popcount） */
uint8_t popcount = 0U;
uint8_t tmp = or_mask;
while (tmp) {
    popcount++;
    tmp &= (uint8_t)(tmp - 1U);  /* 清除最低位的 1 */
}
if (popcount >= MID_LINE_EMG_MIN_SENSORS) {  /* >= 4 路检测到 */
    /* 触发停车 */
}
```

**修改点 4：新增阈值宏**（文件顶部宏定义区，第 62 行 `MID_LINE_EMG_WINDOW` 附近）
```c
/* 紧急停车触发阈值：窗口内至少有 N 路检测到黑线即触发
 * 原值 5 路 = 全部检测到；新值 4 路 = 任意 4 路检测到（更宽松）
 */
#define MID_LINE_EMG_MIN_SENSORS  (4U)
```

**修改点 5：文件头及各函数注释**

## 六、假设与决策

1. **引脚顺序假设**：OUT6=PB24, OUT7=PB20, OUT8=PA22（用户未明确新增3引脚与OUT6/7/8的对应关系，按用户列出顺序"PB24、PB20、PA22"对应 OUT6/7/8）
2. **编码假设**：所有目标文件当前为 GB2312 编码（Read 时注释显示乱码佐证），修改后保持 GB2312
3. **权重方案**：采用等间距权重 -3.5~+3.5（间距均为1），与 `mid_chassis.c:19` 已有注释一致。虽然用户描述的物理间距中间(5)比两侧(11)近一半，但用户明确选择了此方案
4. **emergency 窗口大小**：保持 `MID_LINE_EMG_WINDOW=30`（150ms）不变，与传感器数量无关
5. **OLED 显示**：当前 OLED 只显示运行时间（不显示 IR 状态），无需改动显示逻辑
