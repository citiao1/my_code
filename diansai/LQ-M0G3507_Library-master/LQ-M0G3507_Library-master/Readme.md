# 龙邱科技`TIMSPG3507`开源例程库

## 1-简介

龙邱科技`TIMSPG3507`软件示例程序开源例程库，含基础外设使用例程，`OLED`屏幕、电机、编码器、陀螺仪等驱动应用例程，为电赛适配的各种外设资源使用例程等，针对龙邱产品模块和常用外设资源移植驱动例程，以方便参加电赛和使用我们产品的各位入门学习使用。

## 2-开发环境

- 开发环境：`Keil uVision5 MDK`
- 工具：`LQ-ARMLINK-V9` 下载器。
