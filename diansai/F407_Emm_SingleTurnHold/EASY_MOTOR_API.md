# EMM 双电机简易接口

现在不需要在业务代码中直接调用 `Emm_V5_Pos_Control()`、UART4 DMA 或电机状态机。

## 直接设置角度

```c
EMM_SetAngle(90.0f, 120.0f);
```

含义：

- 电机 1 绝对转到 `+90°`。
- 电机 2 绝对转到 `+120°`。
- 正数为顺时针，负数为逆时针。
- 两个角度的允许范围均为 `-360.0°` 到 `+360.0°`。

函数返回 `1` 表示角度有效并已保存，返回 `0` 表示角度越界或不是有效数值。

## 当前工程已经自动完成的调用

初始化部分已经写好：

```c
EMM_Init();
```

主循环也已经写好：

```c
while (1)
{
    EMM_Run();
}
```

因此在当前工程中，你以后只需要在按键、蓝牙命令或自己的控制逻辑中调用
`EMM_SetAngle()`，不需要重复编写上面两段。

## 四个接口

| 接口 | 用途 | 是否必须由业务代码调用 |
| --- | --- | --- |
| `EMM_Init()` | 初始化 UART4 DMA 接收和双电机状态机 | 当前 `main.c` 已调用一次 |
| `EMM_Run()` | 处理串口回复、回零、同步运动、到位检测和外力回正 | 当前主循环已持续调用 |
| `EMM_SetAngle(a1, a2)` | 设置两台电机的绝对目标角度 | 需要改变目标时调用 |
| `EMM_IsOnTarget()` | 判断两台电机是否都已到位并进入保持 | 需要判断完成时可选调用 |

例如：

```c
if (start_flag != 0U)
{
    start_flag = 0U;
    EMM_SetAngle(90.0f, 120.0f);
}

if (EMM_IsOnTarget() != 0U)
{
    /* 两台电机都已到位，并正在保持目标角度。 */
}
```

## 内部自动执行的过程

调用 `EMM_SetAngle(90.0f, 120.0f)` 后，内部会自动：

1. 检查两个角度是否在允许范围内。
2. 根据每圈 `3200` 脉冲换算两个绝对位置。
3. 给地址 `1` 的电机装载 `90°` 目标。
4. 给地址 `2` 的电机装载 `120°` 目标。
5. 向广播地址 `0` 发送同步启动。
6. 轮流查询两台电机实际角度。
7. 两台连续两组采样都进入 `1.5°` 容差后转入保持状态。
8. 保持时若连续三组采样发现外力偏移，自动回到 `90°` 和 `120°`。

调用本身不阻塞等待电机运动完成。这样主循环仍能继续处理按键、蓝牙和 OLED。

## 连续设置新目标

运动过程中可以再次调用：

```c
EMM_SetAngle(30.0f, -45.0f);
```

状态机会尽快用新目标接管。短时间连续调用多次时，以最后一次调用的两个角度为准。

上电自动回零尚未结束时调用也不会丢失，目标会先保存，回零完成后自动执行。

## 和蓝牙、按键的关系

- 蓝牙 `SET,900,1200` 最终也会调用 `EMM_SetAngle(90.0f, 120.0f)`。
- PE0 按键仍保留“每按一次，两台相对上次目标顺时针增加约 30°”的功能。
- `EMM_SetAngle()` 是绝对坐标；重复调用 `EMM_SetAngle(90, 120)` 不会继续累加。

## 串口封装范围

业务代码不再包含 `motor_uart.h`，也不再直接调用 `motor_uart_init_internal()`、
`motor_uart_process_internal()`。
UART4 的 DMA 接收启动、Receive-to-IDLE 回调、位置帧解析和错误恢复都在电机模块内部。

CubeMX 生成的 `MX_DMA_Init()`、`MX_UART4_Init()` 仍属于芯片底层外设初始化，已经在
`main.c` 的自动生成区域执行，不需要在自己的控制代码中重复调用。
