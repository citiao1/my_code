# BLE 双电机网页上位机

1. 重新烧录工程中的最新 `MDK-ARM/F407_Emm_Normal.hex`。
2. 完全关闭旧的 Python/EXE 上位机，避免它占用蓝牙模块。
3. 双击 `start_web.bat`，使用自动打开的 Edge 或 Chrome 页面。
4. 点击“连接设备”，在浏览器列表中选择要使用的 BLE 串口模块，名称不限。
5. 分别输入两台电机的目标角度并点击“同步转到目标角度”。

网页必须通过 `http://127.0.0.1:8000` 打开，不能直接双击 `index.html`。Web
Bluetooth 需要安全上下文，浏览器把本机 `localhost` 地址视为安全上下文。

网页使用浏览器的全部设备选择模式，不再按 `BT04-A` 名称过滤。所选模块需要
提供 `FFE0` 串口服务；经典蓝牙 SPP 不受 Web Bluetooth 支持。

网页沿用 `diansai_test/vehicle-console` 的特征选择方法：`FFE1` 可写时优先使用，
否则使用 `FFE2`；特征支持普通写入时优先选择 `writeWithResponse`，仅在
不支持时使用 `writeWithoutResponse`。`FFE1` 始终用于
接收通知。连接成功后，通信日志会显示实际选择的特征和写入方式。命令格式为：

```text
SET,300,600\r\n
```

表示电机 1 转到 +30.0 度，电机 2 转到 +60.0 度。

发送后网页日志应先显示“BLE 已写入”，随后收到 `OK,SET,...`。OLED 上的
`BT` 应按收到的字节数增加，`CMD` 应增加 1。正常状态路径为
`05 -> 12 -> 13 -> 08`，运动完成后回到 `05`。

如果网页能实时显示角度但发送后 OLED 的 `BT` 不增加，请先确认旧 EXE 已经
完全退出，并确认单片机已经烧录最新的 `MDK-ARM/F407_Emm_Normal.hex`。

网页的“蓝牙接收”一行直接显示单片机 USART2 诊断：`BT` 是接收字节数，
`LAST` 是最后字节，`ERR` 是错误数，`RX` 是 HAL 接收状态，`SR` 是 USART2
状态寄存器。正常等待接收时 `RX` 应为 `22`；没有数据时 `SR` 通常为 `00C0`。
