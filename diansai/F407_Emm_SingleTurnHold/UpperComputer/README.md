# BT04-A 双电机上位机

## 运行条件

- Windows 10 或 Windows 11，并启用蓝牙。
- BT04-A 已上电，且没有被手机等其他设备占用。
- 单片机已烧录本工程最新的 `F407_Emm_Normal.hex`。

直接运行发布目录中的 `BT04_Motor_Control_v2.exe`。v2 对这块 BT04-A 的
`FFE2` 使用带确认的 Write Request，避免模块丢弃无响应写入。使用源码运行时，
先执行：

```powershell
python -m pip install -r requirements.txt
python motor_control.py
```

## 使用方法

1. 点击“连接 BT04-A”，等待状态变成“已连接”。BLE 模式不需要选择 COM 口。
2. 分别填写电机 1、电机 2 的目标角度，范围为 -360.0° 到 360.0°。
3. 点击“同步转到目标角度”。正数为顺时针，负数为逆时针。
4. 界面会显示两台电机的实际角度、当前目标和控制器状态。

## 通信协议

上位机发送 ASCII 文本，以换行结束，角度单位为 0.1°：

```text
SET,300,600
```

表示电机 1 转到 +30.0°，电机 2 转到 +60.0°。单片机接受后回复：

```text
OK,SET,300,600
```

单片机每秒主动返回：

```text
STAT,300,600,300,600,5
```

五个数字依次为电机 1 实际角度、电机 2 实际角度、电机 1 目标角度、电机 2
目标角度和状态机编号。前四项的单位均为 0.1°。

本机实测的 BT04-A 使用 `FFE2` 写入、`FFE1` 通知。上位机也会自动兼容将
收发功能放在同一个特征中的其他 BT04 固件版本。
