# 80C51 串口回显与定时计数仿真

## 打开和运行

1. 用 Proteus 9 打开本目录的 `chuankou.pdsprj`，点击左下角运行按钮。
2. 虚拟终端每约 1 秒显示一条 `Count = 1`、`Count = 2`……。
3. 点击虚拟终端的黑色显示区域，切换英文输入法后输入字符，单片机会将收到的字节原样回显。
4. 修改程序时先停止仿真，用 Keil 打开 `../../chuankou/chuankou.uvproj` 并编译，再重新启动仿真。

已经附带编译完成的 `../../chuankou/Objects/chuankou.hex`。U1 的 Program File 使用该相对路径，移动文件时保留程序目录与仿真目录的相对位置。

## 电路设置

| 项目 | 设置或接线 |
|---|---|
| U1 | AT89C51，标准 12T，Clock Frequency = 11.0592 MHz |
| X1 | 11.0592 MHz，XTAL1/XTAL2 分别接晶振两端，两个 30 pF 电容接地 |
| 电源 | 隐藏 VCC（40 脚）接 +5 V 电源网络，GND（20 脚）接地，EA（31 脚）接 VCC |
| 复位 | 保留现有工程的 RC 上电复位及手动复位按钮 |
| U1 P3.1/TXD（11 脚） | 接虚拟终端 RXD |
| U1 P3.0/RXD（10 脚） | 接虚拟终端 TXD |
| 虚拟终端 | 9600 bps，8 数据位，无校验，1 停止位，非反相 |
| 本地回显 | 关闭（ECHO=0），屏幕出现的输入字符来自单片机回传 |
| RTS/CTS | 按参考图互相短接，XON/XOFF 关闭 |

电路仅保留 AT89C51 最小系统和虚拟终端，已清理交通灯外围与多余 P1 端口标签。RTS/CTS 连线已保存；交付预览及网表对应最终电路。

## 程序对应关系

- 串口方式 1、允许接收：`SCON = 0x50`。
- T1 方式 2 产生 9600 bps 波特率：`TH1 = TL1 = 0xFD`，`SMOD = 0`。
- T0 方式 1 定时：初值 `0x4C00`，标称 50 ms 溢出一次，累计 20 次后计数加 1。
- 接收中断将字节存入队列，主循环回显并发送十进制计数，两个功能同时运行。
- 软件重装计时存在少量误差，计数周期约 1 秒。
