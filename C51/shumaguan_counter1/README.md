# T1 方式2外部计数与共阴极数码管

按本次实验说明新建，保留原有 `shumaguan_int1` 工程。沿用现有的 `main.c + STARTUP.A51 + .uvproj + Objects/ + Listings/` 结构。

## 编译和接线

用 Keil µVision 打开 `shumaguan_counter1.uvproj`，按 F7 编译。芯片 **AT89S51**，晶振 **12 MHz，标准 12T**，HEX 输出为 `Objects/shumaguan_counter1.hex`。

| 引脚 | 接线 |
|---|---|
| P1.0～P1.6 | 共阴极数码管 a、b、c、d、e、f、g，各段串联限流电阻 |
| P1.7 | dp，小数点保持熄灭 |
| 数码管公共阴极 | GND |
| P3.5 / T1 | K01，松开为高电平，按下接地 |

显示段码为高电平点亮。实际实验板如有段驱动器，按其电路和段序连接；裸接时应核对 P1 的高电平驱动能力，必要时增加段驱动器。MCU 的供电、复位、晶振、EA 接线沿用现有最小系统。

## 程序行为

- 初始显示 **0**，每按一次显示下一个数字：`0 → 1 → 2 → … → 9 → 0 → 1 → …`，持续循环。
- T1 为**外部计数模式、方式2（8位自动重装）**，`GATE1 = 0`，`C/T1 = 1`，`M11:M01 = 10`。与 T0 配置合并后 `TMOD = 0x61`。
- `TH1 = TL1 = 0xFF`，P3.5 每出现一次高到低跳变，T1 加1溢出并自动装回0xFF，产生**定时器1中断（interrupt 3）**。没有使用 INT1，也没有用软件按键扫描替代硬件计数。
- T1 中断立即停止计数，记录一次事件；主循环更新显示。按下后的抖动和长按期间不再接受计数。
- T0 方式1提供标称1 ms的消抖采样：初值 `65536 - 1000 = 0xFC18`。按键松开且21次连续采样为高，覆盖至少20 ms后，清除残留计数和溢出标志，再启动 T1。
- 软件锁定用于普通按键消抖。首次下降沿立即计数；对于噪声较大的物理按键，可增加硬件消抖。若输入为高速连续脉冲，此按键锁定策略不适用。

## 使用与核对

1. 上电显示0；按下并松开 K01，逐次检查1～9、0，继续按仍可循环。
2. 长按应只加1；松开稳定后再按应再加1。
3. 实验2为独立工程，与交通灯分别下载运行。两者都使用 P1，不能直接同时连接运行。
