# 外部中断交通灯

用 Keil 打开 `jiaotongdeng_int0.uvproj`，按 F7 编译；HEX 输出到 `Objects`。芯片 AT89C51，时钟 12 MHz、标准 12T。

- P1.0～P1.5：南北绿、黄、红，东西绿、黄、红；沿用原流水灯的低电平点亮接法。
- 正常依次输出 `DE、DD、F3、EB`，每个状态约 1 秒。
- K1 接 P3.2/INT0，松开为高电平、按下接地，下降沿触发。
- 按下后双向红灯同时闪烁：亮 250 ms、灭 250 ms，共 4 次，约 2 秒；随后继续被打断状态的剩余时间。
- 消抖约 20 ms；闪烁期间不接受新的请求，长按不会连续触发，松开稳定后可再次触发。

只创建程序工程，未绘制仿真原理图。软件延时为近似值。
