# 外部中断数码管计数

用 Keil 打开 `shumaguan_int1.uvproj`，按 F7 编译；HEX 输出到 `Objects`。芯片 AT89C51，时钟 12 MHz、标准 12T。

- 共阴极数码管：P0.0～P0.7 依次对应 a、b、c、d、e、f、g、dp，高电平点亮；公共阴极接地。P0 作普通 IO 使用时需外接上拉，并为各段配置限流电阻；如实验板带驱动电路，按板上实际段序连接。
- K1 接 P3.3/INT1，松开为高电平、按下接地，下降沿触发。
- 初始显示 0，每次完整按下、松开计一次，显示 1～9；第 10 次显示 0，并保持 INT1 关闭，再按无效，复位后重新开始。
- 按下、松开均做约 20 ms 消抖；中断服务程序只记录请求。
